# Capability matrix

Status describes this alpha's public interface, not universal accuracy.

| Capability | Status | Boundary |
| --- | --- | --- |
| Research question and local catalog | Tested | Versioned local records; exclusive Store lease |
| Existing evidence and known-source lookup | Tested | Local provenance required |
| GitHub, paper, web discovery | Tested | Public query and network required |
| Standards and technical documents | Tested | Section provenance depends on source format |
| Fresh-source reservation | Tested | Bounded engineering parameter |
| Evidence, deduplication, dossier | Tested | Extractive claims require review |
| YouTube public discovery and recent videos | Limited | Site/API availability can change |
| Optional read-only subscriptions | Limited | User-owned OAuth setup required |
| Caption and description acquisition | Limited | Availability varies by video |
| Media, ASR, speaker, frame | Optional / limited | Separate dependencies, models and source rights |
| Foreground Evidence Watch | Tested | Explicit start; no background service |
| Resource guard and budget reuse | Tested | Live disk/memory checks remain active |
| Catalog-only initial read scheduling | Tested | Single-process exclusive Store lease remains |
| Health and replacement contracts | Experimental / disabled | No automatic production replacement |
